# Dashboard Design System — Institutional Intelligence

## Direction

Technical Minimalism with Glassmorphic Precision. The dashboard targets quantitative portfolio managers, risk engineers and institutional analysts. It prioritizes statistical signal, quantitative conviction and regime changes over decoration.

## Core palette

- Canvas: `#0B0F17`
- Card: `#111827`
- Panel: `#131D2E`
- Border: `#1F2937`
- Primary emerald: `#10B981`
- Precision cyan: `#06B6D4`
- Refuted/risk coral: `#F43F5E`
- Signal amber: `#F59E0B`
- Signal purple: `#8B5CF6`
- Primary text: `#F8FAFC`
- Muted text: `#64748B`

## Typography

- Narrative/UI: Geist
- Metrics/tickers/statistics: JetBrains Mono
- Small section labels: JetBrains Mono uppercase with expanded tracking

## Layout

- Fixed 256px analytical navigation on desktop
- Fixed 56px context bar
- Compact 12-column analytical canvas
- 4–8px spacing rhythm
- Cards use 4–6px radius and 1px borders
- Mobile collapses to a single-column analytical stream

## Semantic use

- Emerald: confirmed findings / positive statistical signal
- Cyan: interactive focus / exploratory metrics / low-inflation regime
- Coral: refuted hypotheses / negative spreads / critical risk
- Amber: secondary regime/category marker
- Purple: secondary asset category

## Chart rules

- Fine dotted grids
- Monospaced tick values
- No decorative 3D effects
- Confidence intervals and zero/parity references must remain visible
- Status color must encode meaning consistently
